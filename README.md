## 🚀 Projeto em Destaque

### 🐾 FinderPetz — Automação para Alimentação de Pets

Projeto acadêmico concluído que une desenvolvimento mobile e automação para facilitar a rotina de alimentação dos animais de estimação.

O FinderPetz conta com um aplicativo desenvolvido em **React Native e Expo**, integrado a um microcontrolador para controlar um mecanismo físico de alimentação.

**Principais funcionalidades:**
- 📱 Aplicativo mobile com interface moderna e responsiva.
- ⏰ Agendamento de horários de alimentação.
- 🤖 Controle de servo motor por meio de microcontrolador.
- 📡 Integração entre software e hardware.
- 📊 Feedback visual e acompanhamento de status.
- 🔔 Notificações para auxiliar o tutor.

**Tecnologias utilizadas:** React Native, JavaScript, Expo, Context API, NativeWind, ESP32/NodeMCU, Arduino e Servo Motor MG995.

🔗 **[Acessar o projeto FinderPetz](https://drive.google.com/drive/folders/1TCKM2gbME7T_E8GawcdmGdHn-T8Ipk3w)**

🎯 **Objetivo:** aplicar conhecimentos de desenvolvimento de software e automação na criação de uma solução prática para o cuidado com os pets.
